# tmp/ — 少量诊断记录

> **用途**：存放少量诊断/排查过程的临时记录（正式结论应沉淀到对应正文）。
> **目标读者**：排查中的开发者与 AI Agent。
> **关联文档**：[docs/README.md](../README.md)；[logging.md](../conventions/logging.md)。

> 状态：生效中（核验于 2026-09-09）。初始为空。

## 规则

- 仅放少量诊断记录；大文件/截图/一次性脚本进 [artifacts/](../../artifacts/README.md)。
- 诊断结束后：有价值结论提炼进正式文档，本目录记录清理。
