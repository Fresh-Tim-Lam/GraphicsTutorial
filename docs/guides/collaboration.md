# collaboration.md — 协作细则

> **用途**：展开 [meta-rules.md](../conventions/meta-rules.md) 的协作纪律为可执行细则：提问、对齐、任务收尾与文档更新节奏。以 meta-rules 为权威源。
> **目标读者**：与人类维护者协作的 AI Agent 及项目负责人。
> **关联文档**：[meta-rules.md](../conventions/meta-rules.md)（权威源）；[AGENT.md](../../AGENT.md)（Boundaries）。

> 状态：生效中（核验于 2026-09-09）。

## 细则

1. **[提问] 存疑即停**：目标/边界不清时不猜测，先列问题；`Ask First` 边界内的动作（结构重构、改目录、发布等）必须先问。
2. **[提问] 反问带选项**：所有反问给 2–4 个选项并附推荐项；用户在选项外给自定义答案时按自定义执行并记录。
3. **[自解] 先用尽自解手段**：能通过读规范/自检/自测解决的问题不抛给用户。
4. **[执行] 对齐后执行**：结论一经确认按结果执行；低风险事务不阻塞等待确认。
5. **[收尾] 任务收尾自检**：按 directory-organization.md 的 DoD 自检（文件落位、索引同步、无临时物残留、无重复正文）。
6. **[文档] 增删同步索引**：新增/移动/删除文档后立即同步父 README 与 docs 登记表，不等用户提示（见 docs-management.md）。
7. **[会话] 上下文承接**：跨会话在 docs/sessions/ 记录要点，供下次继续。
