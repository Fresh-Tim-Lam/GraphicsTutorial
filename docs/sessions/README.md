# sessions/ — 历史对话记录

> **用途**：记录每次开发/协作会话的关键结论与待办承接，实现跨会话上下文延续。
> **目标读者**：AI Agent（新会话开始时读取最近的会话记录）与项目负责人。
> **关联文档**：[docs/README.md](../README.md)；[to-dolist.md](../to-dolist.md)（活跃待办）。

> 状态：生效中（核验于 2026-09-09）。初始为空，从首个开发会话开始记录。

## 记录规范

- 每会话一个文件：`sessions/YYYY-MM-DD-主题-kebab.md`。
- 内容：目标、关键结论（✅/❌/⏳）、产出文件清单、遗留待办（同步至 to-dolist.md）。
