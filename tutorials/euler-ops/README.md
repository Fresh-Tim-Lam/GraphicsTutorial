# euler-ops —— 半边数据结构与欧拉操作

> **用途**：讲清实体造型的**边界表示（B-rep）**与**五个欧拉操作**如何逐步构造/修改拓扑，并给出可跑的构造过程与图示。
> **目标读者**：学习网格数据结构、实体造型的人；需要按欧拉操作编辑拓扑的实现者。
> **关联文档**：权威实现 [halfedge.hpp](../../src/include/gfx/geom/halfedge.hpp)；设计决策 [adr-0009](../../docs/design/adr-0009-halfedge-euler-ops.md)；渲染用到 [projection-3d](../projection-3d/README.md)（3D 线框）。

> 状态：生效中（2026-09-16）。权威实现见 `src/include/gfx/geom/halfedge.hpp`（接口语义以头文件注释为准）。

## 1. 数据结构：五层拓扑

```
Solid(体) ─→ Face(面) ─→ Loop(环) ─→ HalfEdge(半边) ─→ Vertex(顶点)
                              └─ Edge(无向边 = 一对互为 opposite 的半边)
```

| 元素 | 关键字段 | 说明 |
|---|---|---|
| `MeshVertex` | `position`、`halfEdge` | `halfEdge` 指向**以该顶点为起点**的一条半边 |
| `MeshHalfEdge` | `start/end`、`next/prev`、`opposite`、`edge`、`loop` | 环上双向链表 + 配对 |
| `MeshEdge` | `halfEdge` | 一对半边（几何上的"一条边"） |
| `MeshLoop` | `halfEdge`、`face`、`isOuter` | 面的边界；`isOuter=false` 即**内环（孔）** |
| `MeshFace` | `outerLoop`、`loops` | 外环 + 若干内环 |
| `MeshSolid` | `faces` | 体的面集合 |

实现用**索引池**（`std::vector` + 稳定 id）而非指针：id 稳定便于断言与文本输出，删除只标记 `alive`。

## 2. 五个欧拉操作

| 操作 | 作用 | 元素数量变化 | 前提 |
|---|---|---|---|
| **MVFS** | 建体、面、外环、顶点 | S+1, F+1, L+1, V+1 | 无 |
| **MEV** | 在环上加新顶点与连接边 | V+1, E+1（F、L 不变） | v0 在该环上 |
| **MEF** | 用新边把**一个环**拆成两个环 + 新建面 | E+1, F+1, L+1（V 不变） | v0、v1 在**同一环**且不相邻为同一条边 |
| **KEMR** | 删除**桥接边**，把环拆成"外环 + 内环" | E−1, L+1（V、F 不变） | 该边的**两条半边属于同一环** |
| **KFMRH** | 删 donor 面，把其**外环**转为 receiver 面的**内环** | F−1（V、E、L 总数不变） | 同体；donor 只有一个外环 |

本库另提供 `mevInLoop(loop, v0, p)`：顶点同时属于多个环时（MEF 之后很常见）用于**精确指定环**。

> **附加扩展（超出作业要求）**：本库还实现了 `mfkrh`（KFMRH 的逆：把内环摘出成独立面的外环）与
> `mefr`（跨环建面：在两圈平行环之间一次缝出一圈四边形面），用于演示"上下贯穿的方孔立方体"。
> 这两者**超出作业要求，非评分必需**，详见第 7 节。

## 3. 三个容易踩的点

### 3.1 MEV 要处理两种情形

- **情形①**：MVFS 之后环上还没有边 —— 新边的两条半边直接构成闭环；
- **情形②**：环上已有边 —— 在"以 v0 为起点的半边"**之前**插入 `[v0→v1, v1→v0]` 一对半边。

### 3.2 KEMR 的"桥接边"有明确判据

不是随便一条边都能删。**判据**：该边的两条半边属于**同一个环**（即环在此处"折返"）。
典型形态是"外边界 + 桥 + 内圈"的**8 字形环**：删掉桥 ⇒ 环分成外环与内环（内环即"孔"的拓扑）。

> 两条半边互为 `next`（紧邻往返）的边**不行**：删掉只会得到退化环，本实现会拒绝。

### 3.3 欧拉公式只在**封闭体**上成立

`V − E + F = 2(s − h) + r`（s 体数、h 柄/亏格、r 内环数）。本实现不产生柄 ⇒ 封闭单体应有 `V − E + F = 2`。

带边界的中间状态（面片、管道）**不满足**该等式。所以：

- `validate()` 只查**结构一致性**（配对互反、next/prev 互反、环闭合且顶点连续、归属一致、无悬挂引用）；
- 欧拉特征数由 `eulerCharacteristic()` 单独报告，由使用方按场景判断。

## 4. 运行

### 一键脚本（推荐；双击可用）

本目录下的 [run-euler-ops.cmd](run-euler-ops.cmd) —— **双击即出菜单**，也可带参数直接执行：

```
run-euler-ops.cmd image     生成结果图（PNG，并自动打开）
run-euler-ops.cmd window    打开可视化窗口（关闭窗口即退出）
run-euler-ops.cmd test      运行单元测试（ctest）

```

## 5. 权威实现与自测

- 权威实现：[halfedge.hpp](../../src/include/gfx/geom/halfedge.hpp)（`HalfEdgeMesh`：`mvfs` / `mev` / `mevInLoop` / `mef` / `kemr` / `kfmrh` / **`mfkrh`** / **`mefr`** / `validate` / `counts` / `eulerCharacteristic` / `topologyText` / `loopVertices` / `firstInnerLoop`）。
- 单元测试：`ctest --test-dir build -C Release -R test_halfedge`（**176 checks**）：
  - 每个操作一组**满足前提**的用例，检查操作前后的数量与**连接关系**（不只查数量）；
  - 四面体：MVFS + MEV×3 + MEF×3 连续调用 ⇒ `V=4 E=6 F=4`、`V−E+F=2`、每顶点度数 3、无重复边；
  - KEMR：验证"两条半边同环"前提、删边后边 −1 / 环 +1 / 内环出现、被删边不再存活；
  - KFMRH：面 −1、环总数不变、内环 +1、接收面拥有两个环、donor 面不再存活；
  - 立方体掏空：MVFS + MEV×4 + MEF×5 构造 `V=8 E=12 F=6` 立方体，再"桥 + 内圈 + MEF + KEMR"⇒ 出现内环（孔）；
  - MEFR（扩展）：V 不变、E+N、F+N、L+(N−2)、半边 +2N、内环 −2；两环被消费且不再被引用；N 个新面外环均 4 顶点；终态 `V−E+F=2` 且 `V−E+F−内环数 = 0`；
  - 失败路径：非法参数/前提不满足时**拒绝且不改变结构**。

## 6. 已知限制

- 已实现五个基础欧拉操作；`semv`/`jemv`（分割/合并边）、`kev`/`kef`/`kvfs` 等反操作未实现。
  另有**附加扩展** `mfkrh`（KFMRH 的逆）与 `mefr`（跨环建面），见第 7 节，非作业要求。
- KFMRH 限定"donor 只有一个外环、不含内环"；多环 donor 未支持。
- 不做几何有效性检查（自交、非流形、面朝向一致性）；不回收死亡元素（id 单调增长）。
- 不提供网格文件读写（OBJ/OFF 等）与三角化。

## 7. 附加：贯穿孔实体（超出作业要求）

> **声明**：作业只要求 MVFS / MEV / MEF / KEMR / KFMRH 五个操作，且明确"不要求……完整带孔实体建模或额外
> 欧拉操作"。本节内容为**自主扩展，非评分必需**；五个操作本身已完整达标（见第 2、5 节）。

### 7.1 为什么五个操作做不到

要把一个立方体的上下两面各挖一个孔、再把两孔"缝"成一根上下贯通的方管（亏格 1），5 个操作不够用：

1. **"内环 → 独立面"的能力**：`KFMRH` 只把某个面的外环**并成**另一面的内环（面 −1）。构造时常先切出一个
   "盖子"面，需要反过来把它**摘出来**（面 +1）——这是 `mfkrh`。
2. **"跨环建面"的能力**：两个孔口分属上下两个面、是两个**不同环**；要在它们之间缝一圈孔壁，需要一条能
   **同时引用两个不同环**的新操作 —— 这是 `mefr`。

此外还有**半边结构的配额限制**：每条 `Edge` 恰好 2 条方向相反的半边，用 MEV/MEF 逐面拼墙面会导致边被反复
复用/冲突，无法干净地"两环之间一次缝一圈"。

### 7.2 28 步序列的四个阶段

`EulerInteractive.exe` 用 28 步构造"上下贯穿的方孔立方体"，每步都过 `validate()`：

| 阶段 | 步数 | 说明 | 阶段末计数 |
|---|---|---|---|
| ① 外壳 | 1–13 | MVFS + MEV/MEF 连续调用构造**封闭立方体** | `V=8 E=12 F=6 L=6（内环 0）`V−E+F=2 |
| ② 顶面挖孔并 KFMRH 收尾 | 14–20 | 桥 + 内圈 + MEF（盖子）+ **KEMR**（删桥⇒内环）+ **KFMRH**（盖子并回⇒第二个内环）| `V=12 E=16 F=6 L=8（内环 2）`V−E+F=2 |
| ③ 底面同样 | 21–27 | 与②同样手法处理底面 | `V=16 E=20 F=6 L=10（内环 4）`V−E+F=2 |
| ④ `mefr` 收尾 | 28 | `mefr(顶内环, 底内环)`：一次生成 **4 条竖棱 + 4 个内腔壁** | **`V=16 E=24 F=10 L=12（内环 2）`V−E+F=2** |

### 7.3 最终 `--audit` 关键数字

```
=== 最终状态：V=16 E=24 F=10 L=12（内环 2）V-E+F=2 校验：通过 ===
面 0  环数=2  外环 4 顶点：v7(0,2,2) v4(0,0,2) v5(2,0,2) v6(2,2,2)
        内环 4 顶点：v11(0.5,1.5,2) v10(1.5,1.5,2) v9(1.5,0.5,2) v8(0.5,0.5,2)
面 1  环数=2  外环 4 顶点：v3(0,2,0) v2(2,2,0) v1(2,0,0) v0(0,0,0)
        内环 4 顶点：v12(0.5,0.5,0) v13(1.5,0.5,0) v14(1.5,1.5,0) v15(0.5,1.5,0)
  ...（面 2–5 为 4 个侧面、面 8–11 为 4 个内腔壁，外环均 4 顶点 = 上下孔口各 2 点）...
```

- 共 10 个面 = 6 个外表面 + 4 个内腔壁；顶面（面0）与底面（面1）各含 **1 个内环**（孔口）。
- `V−E+F = 2`，而 **`V−E+F−内环数 = 2−2 = 0`** ⇒ **亏格 1**（正是"上下贯穿一个孔"）。

### 7.4 `--selfcheck` 量化结果

```
[自检] 俯视：顶面色像素 = 150328，暖色（内腔壁）像素 = 23932  ⇒ 顶面方孔可见：是
[自检] 仰视：底面色像素 = 150300，暖色（内腔壁）像素 = 23932  ⇒ 底面方孔可见：是
```

俯视/仰视各统计到 **23932** 个内腔壁像素（> 0）⇒ **上下两个方孔都真实可见**。
（孔壁是竖直面，正交正俯视会退化为线段即 0 像素，故自检用**透视**投影，才能像俯视一口井那样看见孔壁。）

### 7.5 两个扩展操作

| 操作 | 语义 | 数量变化 | 前提 |
|---|---|---|---|
| **`mfkrh`** | 把 receiver 面的一个**内环**摘出，成为**新面的外环**（KFMRH 的逆）| F+1（V/E/L 不变）| 环属于该面且是**内环** |
| **`mefr`** | 在两圈平行环之间**一次缝出一圈四边形面**（跨环建面，把两环缝成方管）| E+N、F+N、L+(N−2)（V 不变，内环 −2）| 两环顶点数相等且 ≥3、不同一、不掏空面 |

`mefr` 的关键：对两个环做**几何对位**并取**反向索引** `B_i = q_{off−i}`，使 `B_{i+1}→B_i` 恰是 loopB 的
**己有半边**（复用而非新建）；每张新面 = `VA[i]→VA[i+1]→B_{i+1}→B_i→VA[i]`，其中上、下两条边分别复用
环 A / 环 B 的半边；建完后两环被**消费**。验证见 `tests/test_halfedge.cpp` 用例 10（含失败路径）。

结果图：`output/hollow.png`（面渲染，孔处透出暖色内腔壁）与 `output/hollow.png-wire.png`（线框）。
